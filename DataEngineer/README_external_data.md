# External DATA Bangkok CCTV

| แหล่งข้อมูล                                                                                                 | ข้อมูลที่เก็บ                                                                                                                                                    | โฟลเดอร์     |
| ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ |
| [Open-Meteo](https://open-meteo.com/en/docs/historical-weather-api)                                         | สภาพอากาศรายชั่วโมงของกรุงเทพฯ วันที่ 25–31 ส.ค. 2026 เช่น อุณหภูมิ ฝน และความเร็วลม                                                                             | `weather/`   |
| [วันหยุดไทย](https://github.com/ppraserts/thailand-open-data/blob/main/data/thai-public-holidays/2026.json) | ปฏิทินปี 2026 ที่ระบุวันหยุดและวันสุดสัปดาห์                                                                                                                     | `holidays/`  |
| [BEM](https://investor.bemplc.co.th/th/business-performance/traffic-volume)                                 | ปริมาณรถบนทางพิเศษเฉลี่ยต่อวัน แยกรายเดือนและรายปี หน่วยเป็นพันเที่ยวต่อวัน                                                                                      | `bem/`       |
| [กระทรวงคมนาคม (MOT)](https://datagov.mot.go.th/th/dataset/roadaccident)                                    | อุบัติเหตุบนโครงข่ายถนนของกระทรวงฯ ไฟล์ที่เตรียมแล้วมี 2,228 รายการในกรุงเทพฯ ช่วง ม.ค.–ต.ค. 2026 พร้อมวันเวลา พิกัด และจำนวนผู้บาดเจ็บหรือเสียชีวิตตามที่รายงาน | `accidents/` |
| [OpenStreetMap](https://www.openstreetmap.org/copyright)                                                    | ถนนและทางเดินที่พบในรัศมี 300 เมตรรอบกล้อง 100 จุด พร้อมแนวเส้นทางใน GeoJSON ข้อมูล ณ 22 พ.ย. 2026                                                               | `osm/`       |

ไฟล์ต้นฉบับอยู่ใน `data/external_data/raw/` และไฟล์ที่เตรียมแล้วอยู่ใน `data/external_data/processed/`
