# กฎการ label (Roboflow) — Bangkok CCTV

ใช้กับการแก้กรอบใน Roboflow สำหรับ fine-tune YOLO ทุกคนในทีมต้องใช้กฎเดียวกัน
ไม่อย่างนั้นโมเดลจะสับสน

**หลักใหญ่:** ใช้ 6 class เดิมของ YOLO (COCO) และ label ให้ตรงกับความหมายที่ YOLO ใช้อยู่แล้ว
เราแค่ "แก้สิ่งที่ YOLO ทำผิด" ไม่ได้เปลี่ยนความหมายของ class
การรวม class เพื่อวิเคราะห์ (เช่น car + truck) ทำทีหลังใน gold ไม่ต้องคิดตอน label

---

## 1. Class ทั้ง 6

ห้ามเพิ่ม ลบ หรือเปลี่ยนชื่อ class ใน Roboflow

| Class | ใช้กับ | ไม่ใช่ class นี้ |
|---|---|---|
| `car` | รถเก๋ง, SUV, รถตู้, แท็กซี่, รถอีโคคาร์ | กระบะ → `truck` |
| `truck` | **รถกระบะ** (ทุกแบบ รวมกระบะมีหลังคา), สองแถว, รถบรรทุก 6 ล้อขึ้นไป, รถพ่วง, รถขยะ, รถปูน | รถตู้ → `car` |
| `bus` | รถเมล์, รถทัวร์, รถบัส, มินิบัส | รถตู้โดยสาร → `car` |
| `motorcycle` | มอเตอร์ไซค์, สกูตเตอร์, **ตุ๊กตุ๊ก**, มอเตอร์ไซค์พ่วงข้าง/ซาเล้ง | จักรยาน → `bicycle` |
| `bicycle` | จักรยาน | |
| `person` | **ทุกคนที่มองเห็น**: คนเดินเท้า, คนบนทางเท้า, **คนขี่มอเตอร์ไซค์/จักรยาน**, คนซ้อนท้าย | คนในรถยนต์ (มองไม่เห็น) → ไม่ต้องวาด |

ทำไมกระบะเป็น `truck`: ชุดข้อมูล COCO ที่ YOLO เรียนมาเรียกกระบะว่า truck ถ้าเราเปลี่ยนเป็น car
โมเดลจะสับสนระหว่างความรู้เดิมกับข้อมูลใหม่

---

## 2. คนขี่ = 2 กรอบ

มอเตอร์ไซค์ 1 คันที่มีคนขี่ ต้องมี **2 กรอบซ้อนกัน**:

- `motorcycle` ครอบตัวรถ (ล้อหน้าถึงล้อหลัง)
- `person` ครอบตัวคนขี่ (หัวถึงเท้า)
- มีคนซ้อนท้าย และแยกออกว่าเป็นคนละคน → วาด `person` เพิ่มอีกกรอบ ถ้าแยกไม่ออก วาดกรอบเดียว
- จักรยานใช้แบบเดียวกัน: `bicycle` + `person`

---

## 3. เมื่อไรต้องวาดกรอบ

วาด เมื่อ:

- อยู่บนถนน ไหล่ทาง หรือทางเท้า **วิ่งอยู่หรือจอดอยู่ก็วาด** (รวมถนนฝั่งตรงข้ามด้วย)
- มองเห็นอย่างน้อย **ครึ่งหนึ่ง** (ถูกขอบภาพตัด หรือถูกคันอื่นบัง)
- ดูออกว่าเป็นรถหรือคน แม้จะอยู่ไกลหรือเล็ก

ไม่ต้องวาด:

- เล็กหรือเบลอจนดูไม่ออก (เป็นแค่จุดไฟหรือไม่กี่ pixel)
- กลางคืนเห็นแค่ไฟหน้า/ไฟท้าย มองไม่เห็นรูปร่างรถ
- เงาสะท้อน รถบนป้ายโฆษณาหรือจอ
- ตัวหนังสือหรือเวลาที่กล้องพิมพ์ทับภาพ

ไม่แน่ใจ → **ไม่วาด** และทำแบบเดียวกันทุกภาพ ถ้าเจอกรณีแปลกๆ เขียนไว้ใน Comments ของภาพนั้น

---

## 4. วาดกรอบยังไง

- **กรอบชิดขอบวัตถุ** ไม่หลวม ไม่ตัดเข้าเนื้อวัตถุ
- ถูกบังบางส่วน → ครอบเฉพาะส่วนที่ **มองเห็น**
- **1 วัตถุ = 1 กรอบ** ถ้า YOLO วาดซ้อน 2 กรอบบนรถคันเดียว ให้ลบออก 1 กรอบ
- รถติดกันเป็นแถว → วาดแยกทีละคัน ถ้าแยกไม่ออกจริงๆ ให้วาดเฉพาะคันที่แยกออก

---

## 5. ขั้นตอนต่อ 1 ภาพ

1. **ปรับแสงก่อน:** กดปุ่ม ☀ ใต้ภาพ เพิ่ม Brightness/Contrast (มีผลแค่การแสดงผล ไม่เปลี่ยนภาพจริง) แล้วซูมเข้า เพราะภาพมีขนาดแค่ 352x288
2. **ตรวจกรอบของ YOLO ทีละกรอบ:**
   - ไม่ใช่วัตถุจริง → ลบ
   - class ผิด → แก้ (ที่ผิดบ่อย: กระบะเป็น `car`, รถตู้เป็น `truck`, คนขี่เป็น `motorcycle`)
   - กรอบหลวมหรือเลื่อน → ปรับ
   - ซ้อนกัน 2 กรอบบนวัตถุเดียว → ลบ 1 กรอบ
3. **วาดกรอบที่ YOLO ไม่เจอ:** กวาดตาทั่วภาพ โดยเฉพาะ
   - **มอเตอร์ไซค์ตอนกลางคืนและตอนรถติด** (YOLO พลาดเยอะที่สุด)
   - รถไกลๆ ด้านบนของภาพ
   - คนขี่ที่ยังไม่มีกรอบ `person`
4. ภาพที่ไม่มีอะไรเลย (ถนนว่าง) ไม่ต้องวาดอะไร ถือว่าเสร็จ

---

## 6. แบ่งงานในทีม

- แบ่งตาม **เลขกล้อง** (ตัวเลขหน้าชื่อไฟล์ เช่น `1408_...`) จะได้ไม่แก้ภาพซ้ำกัน
- ก่อนเริ่มจริง ให้ทุกคน label ภาพเดียวกัน 5 ภาพ แล้วเปิดเทียบกัน ถ้าไม่ตรงกัน คุยให้ได้ข้อสรุปแล้วเพิ่มลงไฟล์นี้
